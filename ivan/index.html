All 20 emails across the eight flows, exactly as written in BrandBeacon product email (Ivan plain text) of 9 September. No sentence has been rewritten, reordered, trimmed or added to.

An email here is type. It may add a picture and a button. Nothing else. No filled brand bars, no stat bands, no cards, no score badges, no timelines, no day trackers. Everything those elements used to carry is already in Ivan's sentences, which is where it now stays. The one instruction in each email is the button, and the URL sits under it. Merge tags are set in mono so it is obvious what is dynamic.

Image sizing. A full width image is 16:9, 1920x1080. A row thumbnail is square. Portrait is not used anywhere. The crops on this page are only 320px wide, because that is all the source frames hold, so judge the layout and not the sharpness. Production stills need capturing at 1920x1080.

A button label is an action, not a sentence. Where Ivan wrapped the link in a longer clause, such as If you want to search more brands, competitors, or products, you can try BrandBeacon for 8 days here:, that clause stays in the body in full and the button carries a short action instead. Where his clause was already a short imperative, Start here and Continue here, it becomes the button itself, verbatim, minus the trailing colon. Those two are the only words anywhere on this page that are not exactly as Ivan set them. Grey lines under each title say what the email is doing.
